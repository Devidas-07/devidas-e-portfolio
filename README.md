# Devidas Sabale — Portfolio (React)

This is a React + Vite port of the original static portfolio. It uses Bootstrap for styling and includes a dark mode toggle.

Quick start

1. Install dependencies:

   npm install

2. Start dev server:

   npm run dev

Open http://localhost:5173/ in your browser.

Notes

- Dark mode toggle state is persisted to localStorage.
- Images remain in the `images/` folder and are referenced directly from components.
